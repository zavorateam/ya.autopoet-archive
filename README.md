# Проект: Генератор стихотворений

## Описание
Этот проект представляет собой генератор стихотворений, который сохраняет каждое стихотворение в отдельный файл с порядковым номером. Проект написан на Python и использует кодировку UTF-8 для поддержки кириллицы.

## Структура проекта
- `generate_poems.py` - основной скрипт, который содержит список стихотворений и функции для их сохранения.
- `README.md` - файл с описанием проекта и инструкциями по использованию.

## Использование
1. Убедитесь, что у вас установлен Python.
2. Запустите скрипт `generate_poems.py` с помощью команды:
   ```bash
   python generate_poems.py
   ```
3. Скрипт сохранит каждое стихотворение в отдельный файл с порядковым номером, пропуская уже занятые номера.

## Функциональность
- Скрипт проверяет существующие файлы в текущей директории и пропускает уже занятые номера.
- Каждое стихотворение сохраняется в файл с именем, соответствующим его порядковому номеру.
- Используется кодировка UTF-8 для корректного отображения кириллицы.

## Возможные улучшения
- Добавление возможности генерации стихотворений с помощью искусственного интеллекта.
- Расширение функциональности для работы с различными форматами файлов.
- Добавление интерфейса командной строки для более удобного использования.
